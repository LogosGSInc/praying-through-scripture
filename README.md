# Authored by Grace — Praying Through Scripture

Pilot repository for the **Authored by Grace — Praying Through Scripture** series, a TovTree publication written by **D. W. Smith**.

## Pilot Purpose

This repository governs the controlled creation, review, and field testing of the first *Praying Through Scripture* gold-sample volume.

### Locked House Decisions

- Scripture translation: **King James Version (KJV) only**
- Brand: **Authored by Grace**
- Series: **Praying Through Scripture**
- Human author byline: **D. W. Smith**
- Publisher attribution: **A TovTree Publication**
- Format direction: **8.5 × 8.5 in**
- Cover direction: **full-color cover**
- Content architecture: condition-specific, Scripture-governed devotional pilgrimage
- Default pilot arc: seven days
- No series-scale generation until the gold-sample release gate is satisfied

## Repository Structure

- `prompts/CONTENT_SYSTEM_PROMPT.md` — governing manuscript-generation prompt
- `prompts/REVIEW_SYSTEM_PROMPT.md` — theological, pastoral, medical-safety, editorial, and human-sound review prompt
- `docs/BOOK_BRIEF_TEMPLATE.md` — mandatory pre-generation brief
- `docs/REVIEW_REPORT_TEMPLATE.md` — structured review and mediation output
- `manuscript/` — generated and human-edited pilot manuscript
- `reviews/` — review reports, mediation records, and acceptance evidence
- `pilot/` — participant-facing pilot logistics and feedback artifacts
- `CHANGELOG.md` — controlled decisions and provenance

## Authority

**Scripture governs. The anchor text controls meaning. Commentary explains. Prayer responds.**

Models may generate, analyze, and review. They do not create theological authority. Final publication decisions remain human editorial decisions.

## Status

**Pilot initialization.** Generated material is not publication-ready until it passes the gold-sample release gate.
